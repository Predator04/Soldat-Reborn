# Credits

## Soldat base assets

The sounds (`assets/sfx/`), weapon graphics (`assets/weapons-gfx/`),
gostek body graphics (`assets/gostek-gfx/`), spark effects
(`assets/sparks-gfx/`), interface art (`assets/interface-gfx/`), and
animation files (`assets/anims/*.poa`) are ported from the Soldat base
distribution:

- **Source:** https://github.com/Soldat/base
- **License (assets):** CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/
- **License (Soldat code):** MIT
- **Original author:** Michał "MM" Marcinkowski and Soldat contributors

Assets have been repackaged for Godot 4 (`.import` sidecars generated by
the Godot editor) but their content is unmodified from the upstream
`base/` distribution. Where sprites were split across `foo.png` and
`foo2.png` (mirror-image variants for left-facing draws), both files
ship as-is.

## Music

`assets/music/*.ogg` are renders of the three tracker modules shipped in the
same Soldat base distribution (`shared/sfx/modules/`, CC BY 4.0):

| File | Module | Title / author (from the module's own text) |
|---|---|---|
| `gore.ogg` | `gore.it` | "Gore" — Marshall Anderson, "made for the game SolDat" |
| `necro.ogg` | `necro.it` | "Necromancide" — Marshall Anderson, "for Soldat" |
| `bloody.ogg` | `bloody.xm` | "Bloody Soil" — author not recorded in the module or upstream credits |

Caveat for a paid release: the Gore module's notes thank "anyone whose samples
I used", so the instrument samples inside it have no recorded origin. The
upstream repo licenses the files CC BY 4.0, but if the game is sold, replacing
these three tracks with music of known provenance removes the question.

## Tracerfall (formerly Soldat Reborn)

This game ("Tracerfall", formerly "Soldat Reborn") is a Godot 4.7 rebuild of the Soldat
gameplay feel using the assets above. The Godot code in `scripts/` and
`scenes/` is original to this project.

If you redistribute this project or any derivative that keeps the Soldat
assets, keep this attribution intact and link back to
https://github.com/Soldat/base per the CC BY 4.0 terms.
